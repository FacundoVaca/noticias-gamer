# Bolsillo Gamer

Sitio de noticias de videojuegos que se escribe solo: lee los RSS de medios gamer, agrupa la misma noticia de varios medios, Gemini redacta una nota original en español, se le crea una portada propia y se publica en Cloudflare Pages.

- Carpeta publicada: `public/` (Cloudflare Pages, sin comando de build)
- Configuración: `config.json`
- Guía paso a paso: [GUIA.md](GUIA.md)
