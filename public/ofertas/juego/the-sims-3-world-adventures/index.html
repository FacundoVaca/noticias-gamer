Requisitos del sistema para PC

Mínimos

  • SO: Windows XP SP2 / Windows Vista SP1 / Windows 7
  • Procesador: (XP) P4 a 2.0 GHz o equivalente; (Vista / Windows 7) P4 a 2.4 GHz o equivalente
  • Memoria: (XP) 1 GB de RAM; (Vista y Windows 7) 1.5 GB de RAM
  • Gráficos: 128 compatible con Pixel Shader 2.0
  • DirectX®: 9.0c
  • Disco Duro: 3.5 GB de espacio libre (9.6 GB si se instala junto con The Sims 3) y al menos 1 GB de espacio para el contenido extra y las partidas guardadas
  • Gráficas Soportadas: Familia nVidia GeForce: FX5900 o superior, G100, GT 120, GT 130, GTS 150, GTS 250, GTX 260, GTX 275, GTX 280, GTX 285, GTX 295; Familia ATI Radeon™: ATI Radeon 9500 o superior, X300, X600, X700, X800, X850, X1300, X1600, X1800, X1900, X1950, 2400, 2600, 2900, 3450, 3650, 3850, 3870, 4850, 4870, 4890 o superior; Intel® Graphics Media Accelerator (GMA): Familias GMA 3 y GMA 4
  • *Por favor, ten en cuenta que las GeForce 6100 y 7100 no están soportadas

Cómo calculamos el precio en pesos

Tomamos el precio de la tienda, lo pasamos con el dólar oficial del día (salvo Xbox, que ya está en pesos) y le sumamos IVA 21% y percepción 30%. Es una estimación: el precio final lo define tu banco.
