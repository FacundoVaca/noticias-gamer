Sobre 001 Game Creator

001 Game Creator es un motor de juegos asistido con programación gráfica tanto para usuarios principiantes como avanzados. Los desarrolladores pueden rápidamente prototipar sus ideas, probar sistemas complejos y construir experiencias de un jugador y multijugador online/locales para Windows PC, html5, android y IOS.

Crea juegos sin limites

001 Game Creator se enorgullece de si mismo en ofrecer a los usuarios un diverso conjunto de herramientas y características para crear cualquier tipo de juego que te puedas imaginar:

  • Pc, Steam, Android, IOS, HTML5 con gestos multi táctiles y prueba por medio de red.
  • Multijugador Online/LAN/Red (soporta tanto TCP como UDP)
  • Editor de capas múltiples del mapa con paralajes
  • Sistema de cámara 2D/3D con audio 7.1 3D HD
  • Juegos de Pantalla dividida con soporte múltiple para controles
  • Sistemas de capas de sprites, modelos 3D y efectos de partículas
  • Carga y descarga dinámica de recursos para mejorar el rendimiento/reducción de uso de memoria para juegos largos
  • Diseñador de interfaces
  • Diseñador de gráficos integrado
  • Mecánicas de inteligencia artificial para batallas y rutas de actor
  • Editor de programación gráfica o textual a elección con un depurador de juego, que incluye visibilidad de variables y estadísticas.

Programación Gráfica asistida

001 Game Creator ofrece a los creadores la habilidad de crear juegos intuitivos e imaginativos sin tener conocimientos sobre escribir código. Esto es especialmente beneficioso para los artistas y diseñadores que prefieren un enfoque mas práctico y visual, o para los desarrolladores que no desean pasar horas golpeando su cabeza contra la pared. A diferencia de las aplicaciones tradicionales de programación guiadas por eventos, 001 Game Creator ofrece un gran conjunto de eventos pre elaborados, con la habilidad también de crear eventos personalizados para funciones especificas hechas a la medida para tus juegos.

PC, Steam Html5 y desarrollo móvil todo en uno

001 Game Creator permite a los desarrolladores construir sus propios juegos para computadoras con Windows (exe) – con soporte para el API de Steam (logros, estadísticas, etc.), HTML5 (js/html) y dispositivos móviles (apk), ¡Todo en uno! A diferencia de otros motores similares, 001 Game Creator provee a los desarrolladores con la libertad para crear sus juegos para todas las plataformas disponibles sin pagar nada adicional. Y lo mejor de todo, es que no hay una licencia adicional o honorarios con tus ingresos para vender tus juegos – de modo que si tu compraste una copia de 001 Game Creator puedes vender tus juegos ¡Sin tener que compartir ganancias con nosotros!

Juega videojuegos con todos

001 Game Creator da a los desarrolladores herramientas para crear ambiciosas experiencias online multijugador/cooperativo con las características de red integradas (TCP/IP). Adicional a eso, 001 Game Creator también permite a los desarrolladores crear experiencias multijugador locales de hasta 4 jugadores - con soporte de controles múltiples incluido.

Las posibilidades son infinitas

001 Game Creator desbloquea las puertas a un amplio rango de posibilidades, con la posibilidad de hacer cualquier juego que te imagines. Incluyendo (pero no limitado a) RPGs, dispara todo, juegos de carreras, juegos de pelea, juegos de simulación, plataformas, defensa de la torre, juegos de cartas e incluso ¡Juegos 3D!, si puedes imaginarlo, puedes crearlo con 001 Game Creator.
