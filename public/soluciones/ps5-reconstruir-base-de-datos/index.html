PS5 lenta, con cuelgues o juegos que se cierran: cómo reconstruir la base de datos

El modo seguro de la PS5 tiene opciones para limpiar la caché y reconstruir la base de datos. Te explicamos cuándo usarlas y cómo hacerlo paso a paso.

Guía PlayStation · Actualizada: 22 de noviembre de 2026 a las 09:00 p. m.

Cuando la PS5 anda lenta en los menús, los juegos se cierran con errores que empiezan con CE o la biblioteca muestra cosas raras, una de las soluciones más efectivas es reconstruir la base de datos desde el modo seguro. No borra tus juegos ni tus partidas: reordena cómo la consola tiene indexado el contenido.

Antes de empezar

  • Actualizá el software del sistema y el juego: Configuración, Sistema, Software del sistema.
  • Tené a mano un cable USB para conectar el control: en modo seguro el control funciona solo por cable.

Cómo solucionarlo

  1. Apagá la PS5 por completo (no en modo de reposo). Esperá a que se apague la luz.
  2. Mantené apretado el botón de encendido: soltalo cuando escuches el segundo pitido, unos siete segundos después del primero.
  3. Conectá el control con el cable USB y apretá el botón PS.
  4. Elegí “Borrar caché y reconstruir base de datos”. Primero probá “Borrar caché del software del sistema”.
  5. Si el problema sigue, volvé a entrar y elegí “Reconstruir base de datos”. Puede tardar varios minutos: no apagues la consola.
  6. Si un juego puntual se sigue cerrando, borralo y volvé a instalarlo. Las partidas guardadas quedan en la consola o en la nube con PS Plus.

Si nada funciona

Anotá el código de error exacto que muestra la consola y buscalo en el sitio de soporte de PlayStation, o contactalos desde ahí. Si el problema empezó con un juego recién lanzado, puede ser una falla del juego: en ese caso conviene esperar el parche oficial.

Preguntas frecuentes

¿Reconstruir la base de datos borra mis partidas?

No. Borra la caché y reordena el índice del contenido, pero tus juegos, partidas y capturas quedan.

¿Cada cuánto conviene hacerlo?

No hace falta hacerlo seguido. Usalo cuando notes lentitud, cierres o errores raros.
